Política de Privacidad y Términos de Uso

Última actualización: 23 de abril de 2026

Bienvenido a Mystic Tarot. Tu privacidad es fundamental para nosotros. Este documento explica cómo manejamos la información en nuestra aplicación móvil.

1. Recopilación de Información

Nuestra aplicación está diseñada para respetar tu privacidad. No recopilamos datos personales directamente (como nombre, correo electrónico o ubicación física) en nuestros servidores.

  • Almacenamiento Local (LocalStorage): Tus preguntas e historial de lecturas se guardan exclusivamente en la memoria de tu dispositivo. Si borras la aplicación o los datos de la misma, esta información se perderá.
  • Identificadores de Publicidad: Al utilizar servicios de terceros para publicidad, estos pueden recopilar el ID de publicidad de tu dispositivo Android para ofrecerte anuncios relevantes.

2. Servicios de Terceros (Publicidad)

Esta aplicación utiliza Google AdMob para mostrar anuncios (intersticiales y bonificados). Google puede utilizar identificadores de dispositivos para personalizar anuncios y analizar el tráfico.

Puedes consultar la política de privacidad de Google AdMob aquí: Política de Privacidad de Google.

3. Uso de la Energía y Recompensas

La aplicación ofrece una lectura gratuita diaria. Para obtener lecturas adicionales, el usuario puede optar voluntariamente por visualizar un anuncio de video. La recompensa (energía extra) se otorga tras la visualización completa del anuncio.

4. Exención de Responsabilidad (Aviso Legal)

Mystic Tarot es una aplicación destinada exclusivamente a fines de entretenimiento.

Las interpretaciones de las cartas no constituyen consejos médicos, legales, financieros o psicológicos profesionales. El usuario es el único responsable de las decisiones tomadas tras el uso de esta aplicación. No garantizamos la exactitud de las predicciones.

5. Requisitos de Edad

La aplicación no está dirigida a menores de 13 años. Recomendamos que el uso de aplicaciones de tarot sea supervisado por un adulto o realizado por personas mayores de 18 años.

6. Cambios en esta Política

Nos reservamos el derecho de actualizar este documento en cualquier momento. Se recomienda revisar esta página periódicamente para estar al tanto de cualquier cambio.
